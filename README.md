
# StudySync — Student Study Planner

StudySync is a ReactJS web application that helps students organize their study tasks and track their progress.

## Features

- Add study tasks with a title, subject, deadline, and priority.
- Validate user inputs and display meaningful error messages.
- Display success messages after adding tasks.
- Mark tasks as completed or pending.
- Filter tasks by status.
- Delete tasks.
- Save tasks in browser localStorage.
- Responsive user interface.

## Technologies Used

- ReactJS
- Vite
- JavaScript
- HTML
- CSS
- Browser localStorage

## Run Locally

1. Install Node.js.
2. Clone the repository.
3. Open the project directory in a terminal.
4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown in the terminal.

## Build

```bash
npm run build
```

## Project Purpose

This project demonstrates React components, state management, event handling, client-side form validation, and interactive functionality.
